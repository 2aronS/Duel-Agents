# Changelog

All notable changes to this repo are documented here. This project follows
[Semantic Versioning](https://semver.org/).

## [Unreleased]

- Package READMEs for `@duel-agents/core`, `@duel-agents/sdk`, and `@duel-agents/install`.
- Example env templates for Cursor and OpenClaw.
- Expanded test coverage for config, SDK, and CLI helpers.

## [0.1.0]

- `@duel-agents/core`: API key validation, proxy URL resolution, per-target env
  maps, OpenClaw config patching, and live connectivity checks.
- `@duel-agents/sdk`: TypeScript client for the OpenAI and Anthropic compatible
  endpoints.
- `@duel-agents/install`: installer CLI for Claude Code, Cursor, Codex, and OpenClaw.
- Python packages: `langchain-duel` and `llama-index-llms-duel`.
