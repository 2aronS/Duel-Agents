# Duel Agents

[Duel Agents](https://duelagents.com) is a routing layer for LLM apps. It runs
each prompt against multiple models and bills the cheapest answer that still
wins, behind an OpenAI-compatible proxy at `https://duelagents.com/v1`.

## Installation and Setup

Install the integration package:

```bash
pip install -U langchain-duel
```

Create an API key at
[duelagents.com/dashboard/settings](https://duelagents.com/dashboard/settings)
(an active subscription is required) and set it:

```bash
export DUEL_API_KEY="duel_<prefix>_<secret>"
```

## Chat models

See a [usage example](/docs/integrations/chat/duel).

```python
from langchain_duel import ChatDuel

llm = ChatDuel(model="duel-auto")
```

Use `"duel-auto"` to let Duel pick the model, or pass a specific model name
(for example `"gpt-4o-mini"` or `"claude-3-5-haiku-latest"`) to route to that
provider.
